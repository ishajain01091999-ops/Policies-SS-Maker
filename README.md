# Policies Screenshot Maker

A Streamlit-based automation tool that captures **full-page screenshots of websites** and allows users to download them as a ZIP file.

## Features

* Capture **full-page website screenshots**
* Supports **manual URL input**
* Supports **bulk URLs**
* Upload URLs using **Excel or CSV**
* Automatically stitches full-page screenshots
* Download all screenshots as **ZIP**

## Tech Stack

* Python
* Streamlit
* Selenium
* Pandas
* Pillow

## Installation

Clone the repository:

```
git clone https://github.com/your-username/repository-name.git
cd repository-name
```

Install dependencies:

```
pip install -r requirements.txt
```

Run the app:

```
streamlit run app.py
```

## Usage

1. Provide URLs manually or upload an Excel/CSV file.
2. Click **Start Capture**.
3. The app captures screenshots of each website.
4. Download all screenshots as a ZIP file.
